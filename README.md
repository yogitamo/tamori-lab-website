# Tamori Lab website

Official website of the Tamori Lab at the University of Louisiana at Lafayette.

This repository contains a static HTML site published with GitHub Pages. Changes pushed to the `main` branch are deployed by the GitHub Actions workflow in `.github/workflows/pages.yml`.

## Local preview

Run a local web server from the repository root, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
